# Descargar TubeLiviano 0.5.1

**[Descargar TubeLiviano_Portable_0.5.1_x86.zip (53,48 MB)](https://github.com/kbdfh98uv/TubeLiviano/raw/refs/heads/main/releases/TubeLiviano_Portable_0.5.1_x86.zip)**

Extraé todo el ZIP **en una carpeta nueva**, sin copiar encima de la versión
anterior, y abrí `TubeLiviano.exe`. El título debe mostrar **0.5.1**.
Incluye VLC 3 x86, motores separados
para XP y Windows moderno, QuickJS, clips offline y código fuente propio MIT.
No ejecutes el EXE desde dentro del archivo comprimido.

La 0.5.1 corrige la selección del motor cuando Windows informa una versión por
compatibilidad, aísla el entorno de yt-dlp y muestra los fallos DLL dentro de la
ventana. La prueba de este cambio en el equipo XP reportado sigue pendiente;
los motores upstream mantienen sus versiones verificadas. Consultá las
[instrucciones](../README.md) y los [resultados de validación](../docs/VALIDACION.md).

También está disponible el [archivo de fuentes upstream de terceros](https://github.com/kbdfh98uv/TubeLiviano/raw/refs/heads/main/releases/TubeLiviano_ThirdParty_Sources_0.5.1.zip)
(45,69 MB). El código propio es MIT; las dependencias conservan sus licencias y
las limitaciones de provisión de fuentes descritas en [THIRD_PARTY.md](../THIRD_PARTY.md).

Las sumas SHA-256 de ambos archivos están en [SHA256SUMS.txt](SHA256SUMS.txt).
